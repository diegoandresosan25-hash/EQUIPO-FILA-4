# Minijuego Web con Sistema de Usuarios

## Descripción del proyecto
Este proyecto consiste en el desarrollo de un minijuego web accesible desde el navegador, cuyo objetivo es ofrecer una experiencia de juego sencilla e interactiva. El juego permite al usuario iniciar una partida, interactuar con la mecánica principal y obtener una puntuación al finalizar la partida.

El proyecto se desarrolla siguiendo los principios de las metodologías ágiles, concretamente Scrum, organizando el trabajo en sprints y utilizando un tablero Kanban para la gestión de tareas.

---

## Objetivo del Sprint 1
El objetivo del primer sprint es desarrollar un prototipo funcional del minijuego que permita jugar una partida básica desde el navegador. Este prototipo incluye la interfaz inicial, la lógica principal del juego y un sistema de puntuación simple, sirviendo como base para futuras mejoras.

---

## Funcionalidades incluidas
- Interfaz web básica del minijuego.
- Inicio y finalización de una partida.
- Lógica principal del juego.
- Sistema de puntuación simple.
- Control básico de jugador (usuario anónimo).
- Estructura inicial del proyecto y documentación básica.

## Estructura del proyecto
/
├── index.html # Página principal del minijuego
├── css/
│ └── styles.css # Estilos generales del juego
├── js/
│ └── game.js # Lógica principal del minijuego
├── assets/
│ └── img/ # Recursos gráficos (imágenes, iconos, etc.)
└── README.md # Documentación del proyecto

Esta estructura permite separar claramente la presentación, la lógica y los recursos del juego, facilitando el mantenimiento del código y el trabajo colaborativo en el equipo.

---

## Cómo ejecutar el proyecto
1. Clonar el repositorio en local.
2. Abrir el archivo `index.html` en un navegador web moderno.
3. Introducir el nombre del jugador (opcional).
4. Iniciar una partida y jugar.

---

## Metodología de trabajo
El equipo trabaja bajo la metodología Scrum, definiendo objetivos claros por sprint y gestionando las tareas mediante un tablero Kanban en GitHub. Cada funcionalidad se desarrolla en una rama independiente y se integra mediante Pull Requests revisados por el equipo.
